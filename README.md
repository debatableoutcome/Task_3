# Task_3 — UI автотесты Stellar Burgers

Проект содержит автотесты для веб-приложения **Stellar Burgers**.

## Используемые технологии

* Python
* Selenium WebDriver
* Pytest
* Allure Report
* Паттерн Page Object Model
* Кроссбраузерный запуск (Google Chrome и Mozilla Firefox)

---


## Покрытый функционал

### Восстановление пароля

Проверено:

* переход на страницу восстановления пароля по кнопке «Восстановить пароль»
* ввод email и клик по кнопке «Восстановить»
* клик по кнопке показать/скрыть пароль делает поле активным

---

### Личный кабинет

Проверено:

* переход по клику на «Личный кабинет»
* переход в раздел «История заказов»
* выход из аккаунта

Для тестов создаётся тестовый пользователь через API.

---

### Основной функционал

Проверено:

* переход по клику на «Конструктор»
* переход по клику на «Лента заказов»
* клик по ингредиенту открывает модальное окно с деталями
* модальное окно закрывается по крестику
* при добавлении ингредиента увеличивается счётчик
* авторизованный пользователь может оформить заказ

---

### Раздел «Лента заказов»

Проверено:

* клик по заказу открывает модальное окно
* заказ из «Истории заказов» отображается в общей ленте
* при создании нового заказа увеличивается счётчик:

  * «Выполнено за всё время»
  * «Выполнено за сегодня»
* после оформления заказа его номер появляется в разделе «В работе»

---

## Принципы реализации

* Тесты независимы друг от друга
* Каждый тест проверяет конкретное поведение
* Нет жёстких зависимостей между тестами
* Используются ожидания WebDriverWait
* Реализована обработка overlay и перехвата кликов
* Нет лишних зависимостей и закомментированного кода

---

## Запуск проекта

### 1. Создать виртуальное окружение

```
python -m venv venv
venv\Scripts\activate
```

### 2. Установить зависимости

```
pip install -r requirements.txt
```

### 3. Запуск тестов

```
pytest -v
```

---

## Allure отчёт

Генерация результатов:

```
pytest --alluredir=allure/allure-results
```

Генерация отчёта:

```
allure generate allure/allure-results -o allure/allure-report --clean
```

Открыть отчёт:

```
allure open allure/allure-report
```
